## Bạn sẽ học được gì?

- **Setup A → Z**: Cài Claude Code đúng cách trên Windows / macOS / Linux, các permission mode, mcp servers, hooks.
- **Workflow thực chiến**: Cách viết `CLAUDE.md`, plan trước, commit nhỏ, quản lý token cost.
- **Toolkit của mình**: Bộ subagents, hooks, slash commands, MCP servers mình đang dùng hàng ngày — đóng gói sẵn để bạn cài 1 lệnh.
- **Case study thực tế**: Cách mình dùng Claude Code build website này, build ducopc Studio, automation cho khách.
